New MCP tool `memory_context(task)`: proactive, theme-based context injection (opt-out via `MCP_CONTEXT_INJECTION_ENABLED`). Given a task, returns the beliefs/memories relevant to the theme (ranked by relevance×confidence, not blind top-N by confidence) within a token budget, with confidence exposed. Records an `injection` usage event, so the agent can later measure injection hit-rate. Graceful fallback to top-confidence when embeddings are unavailable; best-effort, never breaks. Closes the learning-loop injection layer (L3).
