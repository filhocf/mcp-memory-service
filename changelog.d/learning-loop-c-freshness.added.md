- Learning-loop freshness (frente C): when the same fact exists in multiple active versions, context injection now prefers the most recently updated one. A bounded recency boost (cap 0.1, 1-day half-life, opt-in MCP_INJECT_FRESHNESS) breaks ties within a relevance×confidence band without inverting a materially more relevant older belief. Future timestamps (clock skew across hosts) are clamped so the boost stays in [0, 0.1] and never overflows. Zero DDL (uses existing beliefs.created_at/updated_at).
