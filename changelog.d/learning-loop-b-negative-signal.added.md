- Learning-loop negative use-signal (frente B): a belief injected into context N times (MCP_BELIEF_UNUSED_THRESHOLD, default 3) whose source memories never reappear in later retrievals loses confidence (MCP_BELIEF_UNUSED_PENALTY, default 0.20) each consolidation cycle and, on crossing the confidence floor, is superseded and leaves the injection top-k. Opt-in via MCP_BELIEF_USE_FEEDBACK, reversible (per-cycle haircut off freshly-derived confidence), zero DDL (counter in beliefs.metadata, signal derived from usage_events). Reset when the belief becomes useful again.
