Usage telemetry (opt-out via `MCP_USAGE_TELEMETRY`, default on): the service now records retrieval and feedback events in an append-only `usage_events` table and exposes aggregated proveito metrics (`get_usage_metrics`): retrieval/feedback counts, feedback coverage, latency p50/p95 per tool. Privacy-safe (only `query_hash`, never raw queries); best-effort writes never break the read path. Feedback events are wired into the real `rate_memory` flow. First step of learning-loop observability — lets the agent measure whether features actually help. v1 is sqlite-vec only.
